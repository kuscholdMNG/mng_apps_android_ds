## Tokens (generated, DEC-04)

`tokens/MngBrandColors.kt and tokens/flavors/<flavor>/res/values/mng_brand_colors.xml` is generated by Style Dictionary from the Core repo's `tokens/` (DTCG). **Never edit it here**: change the Core data, then run `npm run tokens && npm run build` in `mng_apps_core_ds`. Usage: `MngBrandPalettes.TDP.navbar` (Compose) or `@color/mng_brand_navbar` from the flavor XML; `MngBrandPalettes.forMarket("tdp")`. Every color is written from its exact hex bytes; hex and RGB for each market are in Core `docs/BRAND-COLORS.md`.
